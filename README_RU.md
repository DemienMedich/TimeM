# Приложение для управления временем и борьбы с прокрастинацией

Комплексное приложение на C++, разработанное для помощи пользователям в эффективном управлении временем и борьбе с прокрастинацией через управление задачами, отслеживание времени и технику Помодоро.

## Функции

### Управление задачами
- Создание, редактирование и удаление задач
- Установка уровней приоритета с использованием матрицы Эйзенхауэра (Срочно/Важно)
- Добавление сроков выполнения задач
- Отслеживание статуса выполнения задач
- Организация задач с помощью подзадач

### Отслеживание времени
- Отслеживание времени, потраченного на конкретные задачи
- Приостановка и возобновление отслеживания времени
- Просмотр статистики времени для каждой задачи
- Анализ шаблонов продуктивности

### Техника Помодоро
- Настраиваемая продолжительность работы и перерывов
- Опция длинного перерыва после определенного количества сессий
- Отслеживание сессий и статистика
- Визуальное отображение таймера

### Статистика и отчетность
- Просмотр показателей выполнения задач
- Анализ времени, потраченного на различные задачи
- Отслеживание истории сессий Помодоро
- Мониторинг тенденций продуктивности

### Сохранение данных
- Сохранение задач и настроек в файлы
- Загрузка данных предыдущих сессий
- Автоматическое резервное копирование файлов данных

## Начало работы

### Предварительные требования
- Компилятор, совместимый с C++17
- CMake 3.10 или выше

### Сборка приложения

1. Клонируйте репозиторий
```
git clone https://github.com/username/time-management-app.git
cd time-management-app
```

2. Создайте директорию для сборки
```
mkdir build
cd build
```

3. Сгенерируйте файлы сборки с помощью CMake
```
cmake ..
```

4. Соберите приложение
```
cmake --build .
```

### Запуск приложения
```
./TimeManagementApp
```

## Руководство по использованию

### Главное меню
Приложение запускается с главным меню, предоставляющим доступ ко всем функциям:
1. Управление задачами
2. Отслеживание времени
3. Таймер Помодоро
4. Статистика
5. Настройки
6. Выход

### Управление задачами
- **Просмотр задач**: Просмотр всех, ожидающих или выполненных задач
- **Добавление задачи**: Создание новых задач с названием, описанием, приоритетом и сроком выполнения
- **Редактирование задачи**: Изменение существующих деталей задачи
- **Удаление задачи**: Удаление задач из системы

### Отслеживание времени
- **Начать отслеживание**: Начать отслеживание времени для выбранной задачи
- **Пауза/Возобновление**: Временно остановить или продолжить отслеживание времени
- **Остановить отслеживание**: Завершить сеанс отслеживания и сохранить время для задачи

### Таймер Помодоро
- **Начать Помодоро**: Начать рабочую сессию (по умолчанию: 25 минут)
- **Пауза/Возобновление**: Временно остановить или продолжить текущую сессию
- **Проверить статус**: Просмотр текущего типа сессии, оставшегося времени и прогресса

### Статистика
- **Статистика задач**: Просмотр показателей выполнения и распределения задач
- **Статистика времени**: Анализ времени, потраченного на различные задачи
- **Статистика Помодоро**: Отслеживание завершенных сессий и шаблонов продуктивности

### Настройки
- **Настройки Помодоро**: Настройка продолжительности работы, перерывов и количества сессий
- **Сохранение/Загрузка настроек**: Сохранение ваших предпочтений между сессиями

## Техники борьбы с прокрастинацией

В этом приложении реализовано несколько проверенных стратегий борьбы с прокрастинацией:

1. **Разбиение задач**: Разбивайте большие задачи на меньшие, управляемые подзадачи
2. **Матрица приоритетов**: Используйте матрицу Эйзенхауэра для фокусировки на наиболее важных задачах
3. **Техника Помодоро**: Работайте в сфокусированных интервалах с запланированными перерывами
4. **Осознание времени**: Отслеживайте потраченное время для повышения ответственности
5. **Визуализация прогресса**: Наблюдайте за своими достижениями для поддержания мотивации
