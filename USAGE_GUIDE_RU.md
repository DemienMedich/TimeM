# Приложение для управления временем и борьбы с прокрастинацией - Руководство пользователя

## Начало работы

После сборки приложения вы можете запустить консольную или GUI версию:

### Консольная версия
```
./TimeManagementApp
```

### GUI версия
```
./TimeManagementAppGUI
```

## Консольный интерфейс

### Главное меню

Консольное приложение начинается с главного меню, предоставляющего доступ ко всем функциям:

1. **Управление задачами** - Создание и управление вашими задачами
2. **Отслеживание времени** - Отслеживание времени, потраченного на задачи
3. **Таймер Помодоро** - Использование техники Помодоро для борьбы с прокрастинацией
4. **Статистика** - Просмотр статистики продуктивности
5. **Настройки** - Настройка параметров приложения
6. **Выход** - Закрытие приложения

### Управление задачами

#### Просмотр задач
- Просмотр всех задач, ожидающих задач или выполненных задач
- Задачи отображаются с их ID, названием, приоритетом, сроком выполнения, статусом и затраченным временем

#### Добавление новой задачи
1. Выберите "Добавить новую задачу" в меню управления задачами
2. Введите название задачи
3. При желании введите описание
4. Выберите уровень приоритета (1-4):
   - 1: Срочно и Важно
   - 2: Важно, Не срочно
   - 3: Срочно, Не важно
   - 4: Не срочно и Не важно
5. При желании установите срок выполнения (формат: ГГГГ-ММ-ДД ЧЧ:ММ)

#### Редактирование задачи
1. Выберите "Редактировать задачу" в меню управления задачами
2. Введите ID задачи, которую вы хотите отредактировать
3. Выберите, что редактировать:
   - Название
   - Описание
   - Приоритет
   - Срок выполнения
   - Статус (выполнено/ожидает)

#### Удаление задачи
1. Выберите "Удалить задачу" в меню управления задачами
2. Введите ID задачи, которую вы хотите удалить
3. Подтвердите удаление

### Отслеживание времени

#### Начать отслеживание
1. Выберите "Начать отслеживание" в меню отслеживания времени
2. Выберите задачу для отслеживания, введя ее ID
3. Таймер начнет отсчет для этой задачи

#### Приостановка/Возобновление отслеживания
- Выберите "Приостановить отслеживание", чтобы временно остановить таймер
- Выберите "Возобновить отслеживание", чтобы продолжить отсчет времени для текущей задачи

#### Остановка отслеживания
- Выберите "Остановить отслеживание", чтобы завершить сеанс отслеживания
- Время будет сохранено в общее время, затраченное на задачу

### Таймер Помодоро

#### Запуск Помодоро
1. Выберите "Запустить Помодоро" в меню Помодоро
2. Таймер начнется с рабочей сессии (по умолчанию: 25 минут)
3. После рабочей сессии он переключится на сессию перерыва (по умолчанию: 5 минут)
4. После завершения определенного количества сессий вы получите длинный перерыв (по умолчанию: 15 минут)

#### Приостановка/Возобновление Помодоро
- Выберите "Приостановить Помодоро", чтобы временно остановить таймер
- Выберите "Возобновить Помодоро", чтобы продолжить текущую сессию

#### Проверка статуса
- Выберите "Проверить статус Помодоро", чтобы увидеть:
  - Текущий тип сессии (работа/перерыв)
  - Оставшееся время
  - Количество завершенных сессий

### Статистика

#### Статистика задач
- Просмотр общего количества задач
- Просмотр количества выполненных и ожидающих задач
- Проверка коэффициента выполнения задач

#### Статистика времени
- Просмотр общего времени, затраченного на все задачи
- Просмотр распределения времени по каждой задаче

#### Статистика Помодоро
- Просмотр количества завершенных сессий Помодоро
- Просмотр текущих настроек Помодоро

### Настройки

#### Настройки Помодоро
Настройте свой опыт использования Помодоро:
1. Продолжительность работы (по умолчанию: 25 минут)
2. Продолжительность перерыва (по умолчанию: 5 минут)
3. Продолжительность длинного перерыва (по умолчанию: 15 минут)
4. Количество сессий перед длинным перерывом (по умолчанию: 4)

#### Сохранение/Загрузка настроек
- Сохраните текущие настройки для будущего использования
- Загрузите ранее сохраненные настройки

## Графический интерфейс

### Главное окно

Графическая версия имеет интерфейс с вкладками:
- Вкладка **Задачи** для управления списком задач
- Вкладка **Отслеживание времени** для мониторинга времени, затраченного на задачи
- Вкладка **Помодоро** для использования техники Помодоро
- Вкладка **Статистика** для анализа вашей продуктивности

### Строка меню

Строка меню предоставляет доступ ко всем функциям:

- Меню **Файл**:
  - Новая задача
  - Редактировать задачу
  - Удалить задачу
  - Выход

- Меню **Инструменты**:
  - Начать отслеживание
  - Приостановить отслеживание
  - Остановить отслеживание
  - Запустить Помодоро

- Меню **Настройки**:
  - Язык (Русский/English)
  - Тема (Светлая/Тёмная)
  - Диалог настроек

- Меню **Справка**:
  - О программе

### Вкладка Задачи

#### Список задач
- Просмотр всех задач в табличном формате
- Сортировка задач щелчком по заголовкам столбцов
- Фильтрация задач по статусу (Все/Ожидающие/Выполненные) или приоритету

#### Управление задачами
- **Добавить задачу**: Нажмите кнопку "Добавить задачу" для создания новой задачи
- **Редактировать задачу**: Выберите задачу и нажмите "Редактировать" или дважды щелкните по задаче
- **Удалить задачу**: Выберите задачу и нажмите "Удалить"
- **Завершить задачу**: Выберите задачу и нажмите "Завершить"

#### Цвета задач
Задачи имеют цветовую кодировку по приоритету и статусу:
- Красный: Срочно и Важно
- Желтый: Важно, Не срочно
- Оранжевый: Срочно, Не важно
- Серый: Не срочно и Не важно
- Зеленый: Выполненные задачи

### Вкладка Отслеживание времени

#### Выбор задачи
- Выберите задачу из выпадающего меню
- Нажмите "Начать" для начала отслеживания времени

#### Элементы управления таймером
- **Начать**: Начать отслеживание времени для выбранной задачи
- **Пауза**: Временно остановить таймер
- **Стоп**: Завершить сеанс отслеживания и сохранить время

#### Визуализация
- Просмотр диаграммы распределения времени, показывающей, как время распределяется между задачами
- Просмотр истории сеансов отслеживания времени

### Вкладка Помодоро

#### Отображение таймера
- Большой таймер, показывающий оставшееся время
- Индикатор типа сессии (Работа/Перерыв/Длинный перерыв)
- Индикатор прогресса сессии

#### Элементы управления
- **Начать**: Начать сессию Помодоро
- **Пауза**: Временно остановить таймер
- **Стоп**: Завершить текущую сессию
- **Сброс**: Сбросить счетчик Помодоро

#### Настройки
- Нажмите кнопку "Настройки" для настройки:
  - Продолжительности работы
  - Продолжительности перерыва
  - Продолжительности длинного перерыва
  - Количества сессий перед длинным перерывом

#### История сессий
- Просмотр списка завершенных сессий с отметками времени

### Вкладка Статистика

#### Обзор
- Сводка коэффициентов выполнения задач
- Общее время, затраченное на задачи
- Среднее время на задачу
- Количество завершенных сессий Помодоро

#### Статистика задач
- Круговая диаграмма, показывающая распределение задач по приоритету
- Столбчатая диаграмма, показывающая тренды выполнения задач

#### Статистика времени
- Визуализация времени, затраченного на каждую задачу
- Тренд продуктивности во времени

#### Статистика Помодоро
- Количество завершенных сессий по дням
- Соотношение времени работы и перерывов

### Диалог настроек

#### Общие настройки
- **Язык**: Выбор между русским и английским
- **Тема**: Выбор между светлой и темной
- **Уведомления**: Включение/отключение уведомлений

- Продолжительность работы

- Количество сессий перед длинным перерывом

- Автоматически начинать рабочие сессии

## Советы по борьбе с прокрастинацией

1. **Разбивайте задачи**: Используйте систему управления задачами для разбиения больших задач на меньшие, управляемые подзадачи.

2. **Эффективно расставляйте приоритеты**: Используйте матрицу Эйзенхауэра (уровни приоритета 1-4), чтобы сосредоточиться на том, что действительно важно:
   - Приоритет 1 (Срочно и Важно): Выполняйте эти задачи немедленно
   - Приоритет 2 (Важно, Не срочно): Запланируйте время для этих задач
   - Приоритет 3 (Срочно, Не важно): Делегируйте, если возможно
   - Приоритет 4 (Не срочно и Не важно): Исключите или минимизируйте затраченное время

3. **Используйте технику Помодоро**: Работайте в сфокусированных интервалах с запланированными перерывами для поддержания продуктивности и предотвращения выгорания.

4. **Отслеживайте свое время**: Осознание того, как вы тратите свое время, повышает ответственность и помогает выявить закономерности продуктивности.

5. **Анализируйте свой прогресс**: Регулярно проверяйте свою статистику, чтобы отмечать достижения и выявлять области для улучшения.

6. **Поддерживайте постоянство**: Используйте приложение ежедневно для формирования продуктивных привычек со временем.

## Сохранение данных

Приложение автоматически сохраняет ваши задачи и настройки при выходе. При перезапуске приложения ваши предыдущие данные будут загружены автоматически.

### Резервное копирование и восстановление
- Используйте диалог настроек для создания резервных копий ваших данных
- При необходимости восстанавливайте данные из резервных копий
