# Приложение для управления временем и борьбы с прокрастинацией - Резюме проекта

## Обзор

Это приложение на C++ разработано для помощи пользователям в эффективном управлении временем и борьбе с прокрастинацией. Оно объединяет управление задачами, отслеживание времени и технику Помодоро в комплексный инструмент для повышения продуктивности.

## Ключевые функции

1. **Система управления задачами**
   - Создание, редактирование и удаление задач
   - Установка приоритетов с использованием матрицы Эйзенхауэра (Срочно/Важно)
   - Добавление сроков выполнения и отслеживание статуса выполнения
   - Поддержка подзадач для разбиения сложной работы

2. **Отслеживание времени**
   - Отслеживание времени, потраченного на конкретные задачи
   - Приостановка и возобновление сеансов отслеживания
   - Анализ распределения времени между различными задачами

3. **Реализация техники Помодоро**
   - Настраиваемая продолжительность работы и перерывов
   - Опция длинного перерыва после определенного количества сессий
   - Отслеживание сессий и статистика

4. **Статистика и отчетность**
   - Показатели выполнения задач
   - Анализ затраченного времени
   - Шаблоны продуктивности

5. **Сохранение данных**
   - Сохранение задач и настроек в файлы
   - Загрузка данных предыдущих сессий
   - Автоматическое резервное копирование файлов данных

## Техническая реализация

### Архитектура

Приложение следует объектно-ориентированному дизайну с четким разделением обязанностей:

- **Класс Task**: Представляет отдельные задачи с их свойствами и поведением
- **Класс TimeTracker**: Обрабатывает функциональность отслеживания времени
- **Класс PomodoroTimer**: Реализует технику Помодоро
- **Класс TaskManager**: Управляет коллекциями задач и операциями над ними
- **Класс FileManager**: Обрабатывает сохранение данных
- **Класс UserInterface**: Предоставляет консольный пользовательский интерфейс

### Шаблоны проектирования

- **Шаблон Одиночка (Singleton)**: Используется для TaskManager для обеспечения единой точки управления задачами
- **Шаблон Наблюдатель (Observer)**: Реализован для уведомлений таймера
- **Шаблон Команда (Command)**: Используется для действий пользовательского интерфейса

### Структуры данных

- **Вектор (Vector)**: Используется для хранения коллекций задач
- **Управление временем**: Пользовательская реализация для отслеживания и расчета временных интервалов

## Сборка и запуск

### Предварительные требования
- Компилятор, совместимый с C++17
- CMake 3.10 или выше

### Инструкции по сборке
```
mkdir build
cd build
cmake ..
make
```

### Запуск приложения
```
./TimeManagementApp
```
